# Digital Resume

The above repo has the Github Action Workflow for automating the process of converting your Markdown Resumes to PDF ( and in the future to more formats) by using the [Action](https://github.com/BaileyJM02/markdown-to-pdf) from [BaileyJM02](https://github.com/BaileyJM02). The Generated PDF is then rendered by Github pages so, this automates the whole process of creating a new shareable link whenever you make a change in your resume!
